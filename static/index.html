Getting Started

  1. Select your trainer — choose which training tool you used.
  2. Browse to your workspace — select the run/workspace folder.
  3. Pick a training run — the dataset is auto-detected from the config.
  4. Choose comparison mode — Person's Likeness or Style Similarity.
  5. Select steps — choose all or narrow to a range.
  6. Run — images are compared and ranked by similarity.

Powered by InsightFace (ArcFace) for face recognition and CSD for style comparison.

Sample Generation

  1. Select your trainer — the tool whose workspace holds your LoRA checkpoints.
  2. Browse to your workspace — same folder you use for evaluation.
  3. Pick a training run — its config is inspected to recognize the base model.
  4. Confirm the model & settings — adjust model/CLIP/VAE paths and sampler.
  5. Add prompts — one image will be generated per prompt, per saved step.
  6. Generate — samples are written to the run's samples folder.

Each saved LoRA step is loaded automatically and sampled with the prompts below.
